## Installation

If you have a GPU and have the drivers installed and up-to-date, the install should be as simple as cloning the repository and using pip. We recommend installing in editable mode with

```bash

   git clone https://github.com/cronos-inria/tractography.git
   cd tractography
   pip install -e .
```

If you would like to use the CPU version, then we recommend using anaconda for the installation

```bash

    conda create -n tractography python=3
    conda activate tractography
    conda install anaconda::binutils
    conda install numpy
    conda install -c conda-forge pocl
    conda install -c conda-forge pyopencl
    git clone https://github.com/cronos-inria/tractography.git
    cd tractography
    pip install -e .
```

## Quickstart (Python)

The example below runs a complete tractography workflow in Python using synthetic test data generated by `test.data.cross()`. It uses the `transport` algorithm and saves a tractogram to disk.

```python

from pathlib import Path

import nibabel as nib

import tractography as tg
import tg.data

# Load the crossing fibres dataset using spherical harmonics. You can replace
# this by your own FOD data.
fod, wm, _ = tg.data.sh.cross()

# Generate seeds from the white-matter mask and track only in the white matter.
n_seeds = 100  # In practice, many more seeds would be used.
seeds = tg.seeds.from_mask(wm.get_fdata(), wm.affine, n_seeds)
fod = tg.nifti.multiply(fod, wm)  # This masks the FOD outside of the WM.

# Load and tweak the transport configuration.
config = tg.configuration.load(tg.Algorithm.TRANSPORT)
config.batch_size = n_seeds

# Run tractography.
tractogram = tg.tractogram(fod, seeds, config)

# Save outputs.
output_dir = Path("quickstart-output")
output_dir.mkdir(parents=True, exist_ok=True)
nib.save(fod, output_dir / "cross_fod.nii.gz")
nib.save(wm, output_dir / "cross_wm.nii.gz")
nib.streamlines.save(tractogram, output_dir / "cross_transport_streamlines.tck")
```
