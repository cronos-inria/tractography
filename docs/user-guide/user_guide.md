The User Guide provides documentation for users of tractography.

See [Domains](domains.md) for an overview of the domain interface, and [Image Domains](image-domains.md) for an example using `tg.domain.Image`.
See [Fields](fields.md) for an overview of the field interface, and [Image Fields](image-fields.md) for an example using `tg.field.Image`.
See [Local Models](local-models.md) for an overview of the models used during tracking, and [Real Symmetric Spherical Harmonics](local-spherical-harmonics.md) for an evaluation example.
See [Diffusion Tensor Imaging](diffusion-tensor-imaging.md) for the six-coefficient tensor model and its directional encoding.
See [Base Algorithm](base-algorithm.md) for the interface implemented by orientation-update algorithms, and [Transport Orientation Algorithm](transport-algorithm.md), [Diffusion Orientation Algorithm](diffusion-algorithm.md), [Deterministic Orientation Algorithm](deterministic-algorithm.md), and [Probabilistic Orientation Algorithm](probabilistic-algorithm.md) for the built-in implementations.
See [Tracking](tracking.md) for the public tractogram workflow and the lower-level OpenCL tracking function.
